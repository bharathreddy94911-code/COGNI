# Demo Backend

This is a **TEMPORARY DEMO BACKEND** built for UI demonstration purposes only.

It is designed to return deterministic, hardcoded API responses that match the exact shape expected by the frontend's API service. It allows developers and stakeholders to click through the complete User and Employee document processing workflows.

### What it does NOT contain:
- No real AI models
- No LangGraph / Ollama
- No database
- No real authentication

The real, AI-powered backend will be connected to the frontend later.

## Setup

```bash
cd demo-backend
npm install
```

## Running

You can run this demo backend from the project root using:
```bash
npm run demo:backend
```

Or run it directly from this directory:
```bash
npm start
```
